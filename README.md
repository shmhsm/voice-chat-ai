# Voice-to-Text AI Assistant

Веб-додаток для миттєвої конвертації голосу в текст. Проект поєднує в собі сучасний інтерфейс на React та потужність нейромереж для розпізнавання мовлення.

---

## Основні можливості

* **Голосовий ввід:** Запис аудіо безпосередньо через браузер одним натисканням.
* **AI Транскрибація:** Високоточне перетворення мовлення в текст за допомогою моделі **Groq/Whisper**.
* **Smart Limits:** Розумна система обмежень — одна безкоштовна спроба для гостів, після чого пропонується перехід на **PRO-план**.
* **Інтуїтивний дизайн:** Чистий інтерфейс з використанням компонентів `shadcn/ui` та анімацій стану запису.
* **Адаптивність:** Коректна робота на мобільних пристроях та десктопах.

---

## Технологічний стек

* **Framework:** [Next.js](https://nextjs.org/) (App Router)
* **Language:** [TypeScript](https://www.typescriptlang.org/)
* **Styling:** Tailwind CSS + CSS Modules
* **Components:** Radix UI / shadcn/ui
* **Auth:** [Clerk](https://clerk.com/)
* **Icons:** Lucide React

---

## Структура проекту

Проект виконаний згідно з вимогами до архітектури:
* `src/components` — кожна папка компонента містить файл `.tsx` та відповідний йому `.module.css`.
* `src/types` — загальні типи (наприклад, `votes.ts`) винесені в окрему директорію.
* `src/lib` — логіка роботи з локальним сховищем та лімітами записів.
